**Работа с памятью**

**Справка**

Память - пронумерованные подряд ячейки. В памяти храним данные, которые не вмещаются в регистры (регистров всего 16, память - большая). Доступ к памяти медленнее, чем обращение к регистрам.

Для работы с памятью используем следующие команды:

- `alloc 100 -> r12` - выделяем блок памяти (100 последовательных ячеек) и записываем индекс первой ячейки в регистр `r12`.

- `store r1 -> [r12]` - запись в память. Можно так же записать в `[r12 + 5]`, `[r12 + r7]`

- `load [r12 + 5] -> r6` - загружаем значение из ячейки памяти номер `r12 + 5`
