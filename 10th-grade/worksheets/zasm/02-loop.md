Пример цикла, который выводит числа от 1 до N

Отступы здесь для удобства чтения

```
read -> r0
mov 1 -> r1

mark loop
    write r1
    add r1, 1 -> r1
    le r1, r0 -> r7
    jumpif r7, loop
```

**A3. Квадраты**

Петю интересует как быстро увеличивается вес деревянного квадрата размером X * X.
Мы знаем что квадрат 1 * 1 весит 1кг.

Вводится число N.

Для всех значений X от 1 до N выведите сколько весит квадрат размера X * X.

**D3. Сумма N чисел**

В классе Б школы номер 1 есть N учеников.

Давайте посчитаем сколько у них всего есть фруктов.

Сначала нам сообщают число учеников в классе, затем каждый ученик сообщает сколько у него есть фруктов.

Выведите одно число – суммарное число фруктов в этом классе (мы считаем что подсчёт идёт настолько быстро, что никто не успевает съесть ни одного фрукта за это время; всё-таки Железяка ведёт подсчёты эффективно)

**E3. Сумма цифр**

На старых телефонах чтобы набрать телефонный номер нужно было вращать колесо с цифрами.
Будем считать что мы поворачиваем колесо на 0, если очередная цифра 0, поворачиваем на 1 если цифра 1 и так далее.
На сколько суммарно за время набора номера мы повернём колесо?
Или, другими словами, какова сумма цифр в номере телефона?
