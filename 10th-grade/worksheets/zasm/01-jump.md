**JUMP**

**Справка**

Для непоследовательного исполнения (в том числе для условий и циклов) используем такие инструкции:

- `mark name` - установит пометку `name` в этом месте программы

- `jump name` - перейдёт к пометке `name`

- `jumpif r6, name` - перейдёт к пометке `name`, если выполнено условие `r6` (то есть в регистре записан не 0).

Для проверки условий используем команды:

- `eq r1, r2 -> r7` - если числа `r1` и `r2` равны запишет в `r7` единицу. Иначе запишет 0.

- `eq`, `ne` проверяют `=`, `=/=` (и записывают результат проверки)
- `gt`, `ge`, проверяют `>`, `>=`
- `lt`, `le` - проверяют `<`, `<=`

Логические операции:

- `not r1 -> r2` - запишет 1, если r1 это 0 и запишет 0 иначе
- `and r1, r2 -> r3` - запишет 1 если `r1` и `r2` истинны
- `or r1, r2 -> r3` - запишет 1 если `r1` или `r2` истинно
- `xor r1, r2 -> r3` - запишет 1 если либо `r1` либо `r2` истинно

Пример:

Проверим что число в диапазоне от 10 до 20

Если не в диапазоне - выведем -1

```
read -> r0

le 10, r0 -> r7
le r0, 20 -> r8
and r7, r8 -> r9

jumpif r9, ok
jump not_ok

mark ok
write r0
jump end

mark not_ok
mov -1 -> r0
write r0
jump end

mark end
```
